To compile this program:
1. Have java installed 

2. Unzip folder to a convenient place in your system.

3. Make sure all of the files are in the same folder, should be named Prog1 if unchanged

4. Navigate to the folder with the files in preferred terminal using "cd" followed by the path of the folder, or 
    shift+right click the folder and click open in terminal, or if in Windows 11 right click the folder and open in terminal

5. Once in terminal at the location of the folder, type "javac Prog1.java"

6. Then type "java Prog1"

7. The file is included in the code, so as long as the SampleInput is in the same folder it should run

8. The program should run and display the output of connected components on the terminal
