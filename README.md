This program finds the connected components in graphs given by an input file.
The input passes in graphs by first giving the number of vertices in the graph, and then the edges between two vertices a and b.
Example of a line: 8 (1,2) (2,3) (3,2) (1,4) (1,5) (6,2) (6,7) (8,2)
The program can take in a text file with multiple lines and will run until there are no lines left to input.

The program may not run if the input from the file is not in the correct format, since we were only given the task
to perform this on the specific format.

The output displays the number of connected components and the vertices in each component.
